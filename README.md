Make sure to download Keil MDK and Terra Term (version 4.105.exe).

After Keil installs, the Pack installer window will pop up. 
In the left hand side of the window, select the vendor Texas Instruments and then select the device MSP432P4xx. 
Select MSP432P401R.
On the right hand side, install the pack Texas Instrument (can be found under Pack).

Download the XDS Driver Download. Extract the zip folder.
Open the extracted folder, click DPInst64 to install it.

Download the TI XDS Driver Download (32 bit windows, latest version).

Open Keil. Go to Projects, then Open Projects, and finally open the Lab Template. Replace the ESET 269 Final Project code in the main.c file.

Execute code with the MSP432 microcontroller using Software Keil MDK.
Use console provided by software Terra Term.
